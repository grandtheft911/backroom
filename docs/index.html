How to install an APK
  1. Tap Download and wait for it to finish.
  2. Open the file from the notification or from Files → Downloads.
  3. If your phone asks, allow installs from this source (Settings → Install unknown apps), then go back and tap Install.

For a new version, just download and install over the old one. Your progress is kept.
